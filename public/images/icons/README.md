# Icon Requirements

The following icons are needed for PWA and favicon support:

## Favicons
- favicon.ico (16x16, 32x32, 48x48 multi-size)
- favicon.svg (vector, any size)
- favicon-16x16.png
- favicon-32x32.png

## Apple Touch Icons
- apple-touch-icon.png (180x180)

## PWA Icons
- icon-192x192.png (192x192)
- icon-512x512.png (512x512)
- icon-192x192-maskable.png (192x192, with safe zone padding)

## Generation Instructions
1. Start with a high-resolution logo (at least 512x512)
2. Use a tool like https://realfavicongenerator.net/ to generate all sizes
3. Place generated files in this directory
4. Update paths in BaseLayout.astro if needed
